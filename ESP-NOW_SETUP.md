# ESP32 LCD Receiver dengan WiFi Manager & ESP-NOW

## Deskripsi Singkat

Kode ini untuk ESP32 LCD yang berfungsi sebagai **receiver** data sensor melalui **ESP-NOW**. LCD menampilkan 6 sensor dalam layout 2 baris × 3 kolom.

## Layout LCD

```
┌─────────────────────────────────────────┐
│ BARIS 1: Temp | Humidity | Pressure    │
│ BARIS 2: Lux  | Fertilizer | Rain%    │
└─────────────────────────────────────────┘
```

### Data yang Ditampilkan

| Baris | Kolom 1 | Kolom 2 | Kolom 3 |
|-------|---------|---------|----------|
| **1** | Suhu (°C) | Kelembaban (%) | Tekanan (hPa) |
| **2** | Lux (lux) | Pupuk | Intensitas Hujan (%) |

## Setup Awal

### 1. Dapatkan MAC Address ESP32 LCD

Upload dan jalankan ini sekali:

```cpp
void setup() {
  Serial.begin(115200);
  WiFi.mode(WIFI_STA);
}
void loop() {
  Serial.println(WiFi.macAddress());
  delay(1000);
}
```

Catat MAC address yang tampil (format: XX:XX:XX:XX:XX:XX)

### 2. Update Konfigurasi

Edit `include/sensor_data.h` dan ganti:

```cpp
#define LCD_RECEIVER_MAC { 0xXX, 0xXX, 0xXX, 0xXX, 0xXX, 0xXX }
```

Dengan MAC address ESP32 LCD Anda (ubah XX dengan nilai hex dari MAC address)

### 3. WiFi Connection

Saat pertama kali boot:

- ESP32 akan membuat WiFi hotspot: **ESP32-TGG-Screen**
- Connect ke hotspot ini dari smartphone
- Akan muncul portal untuk memilih WiFi yang ingin diconnect
- Pilih WiFi Anda dan masukkan password
- Settings akan tersimpan otomatis

Untuk reset WiFi settings, uncomment line di setup():

```cpp
wifiManager.resetSettings();
```

## Cara Kerja

### WiFi Manager

- Otomatis setup WiFi tanpa hardcode SSID/password
- Portal konfigurasi muncul jika tidak bisa connect ke WiFi terakhir
- Settings disimpan di SPIFFS/NVS

### ESP-NOW Receiver

- Listening untuk data dari ESP1 secara wireless
- Tidak perlu internet connection (P2P)
- Range lebih jauh & latency lebih rendah dari WiFi

### Data Structure

Setiap data yang diterima adalah struktur `SensorData`:

```cpp
typedef struct {
  float temperature;    // Baris 1, Kolom 1
  float humidity;       // Baris 1, Kolom 2
  float pressure;       // Baris 1, Kolom 3
  float lux;            // Baris 2, Kolom 1
  float fertilizer;     // Baris 2, Kolom 2
  float rainIntensity;  // Baris 2, Kolom 3
} SensorData;
```

### Display Update

- LCD update otomatis saat menerima data dari ESP1
- Jika tidak ada data selama 5 detik, menampilkan "---"
- Update UI setiap frame (60fps)

## Setup ESP1 (SENDER) - Next Step

Gunakan template di `include/sensor_data.h`:

1. Include header tersebut
2. Setup ESP-NOW dengan MAC address LCD sebagai peer
3. Baca nilai sensor Anda
4. Send struktur SensorData via `esp_now_send()`

Contoh:

```cpp
#include "sensor_data.h"
#include <esp_now.h>

uint8_t broadcastAddress[] = LCD_RECEIVER_MAC;

void setup() {
  WiFi.mode(WIFI_STA);
  esp_now_init();
  
  esp_now_peer_info_t peerInfo = {};
  memcpy(peerInfo.peer_addr, broadcastAddress, 6);
  esp_now_add_peer(&peerInfo);
}

void loop() {
  SensorData data = {
    25.5,  // temperature
    65.0,  // humidity
    1013.0, // pressure
    500.0,  // lux
    80.0,  // fertilizer
    40.0   // rainIntensity
  };
  
  esp_now_send(broadcastAddress, (uint8_t *)&data, sizeof(data));
  delay(1000);
}
```

### Troubleshooting

| Masalah | Solusi |
|---------|--------|
| LCD tidak terkoneksi WiFi | Uncomment `wifiManager.resetSettings()` di setup() |
| Data tidak diterima | Pastikan MAC address LCD benar di ESP1 |
| Data timeout | ESP1 berhenti mengirim? Cek ESP1 apakah sedang aktif |
| WiFi disconnect | WiFi Manager otomatis reconnect (restart diperlukan jika persistent) |

## Notes

- ESP32 LCD mode: WiFi mode untuk WiFi Manager
- ESP-NOW tidak perlu internet (berbeda dengan WiFi biasa)
- Kedua ESP bisa saling kirim via ESP-NOW asalkan pairing done
- Data size: 24 bytes (6 float × 4 bytes)
