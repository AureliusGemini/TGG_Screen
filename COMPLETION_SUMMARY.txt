📡 ESP-NOW COMMUNICATION
═══════════════════════════════════════════════════════════════════

Architecture:
  
  ESP1 (Sensor Node)              LCD (Display Node)
  ─────────────────               ──────────────────
  
  Sensors                         WiFi Manager
    ├─ Temperature      ──ESP──┐   Hotspot: 
    ├─ Humidity        ──NOW──┤   ESP32-TGG-Screen
    ├─ Pressure                │
    ├─ Lux            ────────→  ESP-NOW Receiver
    ├─ Fertilizer              │
    └─ Rain                    │
                              LCD Display (2x3)

Features:
  ✓ P2P wireless (tidak perlu WiFi router)
  ✓ Range: ~200-300 meters
  ✓ Latency: <10ms
  ✓ Data size: 24 bytes (6 float values)
  ✓ Update frequency: customizable (default 1 sec)

struct SensorData {
  float temperature;    // Baris 1, Kolom 1 (°C)

🆘 TROUBLESHOOTING QUICK TIPS
═══════════════════════════════════════════════════════════════════

WiFi Portal tidak muncul?
  → Uncomment: wifiManager.resetSettings()
  → Reupload & reset ESP

Data tidak diterima?
  → Check: MAC address benar?
  → Check: ESP1 sedang mengirim?
  → Check: Serial show "ESP-NOW Data Received"?

LCD menampilkan "---"?
  → Normal jika ESP1 offline (timeout 5 detik)
  → Restart ESP1 untuk test transmission

WiFi keep disconnect?
  → WiFi Manager auto-reconnect (normal)
  → Check: WiFi signal strength
  → Try: Different location if signal weak
