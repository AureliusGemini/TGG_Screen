📡 ESP-NOW BEHAVIOR
═════════════════════════════════════════════════════════════════
• P2P wireless (no WiFi router needed)
• Range: ~200-300 meters (line of sight)
• Latency: <10ms typically
• Power: Efficient for IoT
• Pairing: Auto via MAC address

⚡ INITIALIZATION ORDER
═════════════════════════════════════════════════════════════════
ESP32 LCD (Receiver):
1. Serial init → Debug output
2. Display init → Show "Initializing WiFi..."
3. WiFi Manager → Setup hotspot + auto connect
4. ESP-NOW init → Start listening
5. LVGL init → Load UI
6. Loop → Update labels with received data

ESP1 (Sender):
1. Serial init
2. WiFi.mode(WIFI_STA)
3. esp_now_init()
4. Add peer (LCD MAC address)
5. Loop → Read sensors → Send data

⏱️ TIMING
═════════════════════════════════════════════════════════════════
WiFi Manager: Timeout 120 seconds (then AP mode)
ESP-NOW: Instant receive
Data Timeout: 5 seconds (show "---" if no update)
LVGL Refresh: 60 FPS

📞 COMMON ISSUES
═════════════════════════════════════════════════════════════════
LCD freezing during WiFi setup:
→ Normal, takes ~5-30 seconds depending on WiFi

Data not received:
→ Check: 1) MAC address correct? 2) ESP1 sending? 3) Distance OK?

WiFi keeps disconnecting:
→ WiFi Manager auto-reconnect, check WiFi signal strength

Touch not working:
→ Separate issue from ESP-NOW, check XPT2046 pins
